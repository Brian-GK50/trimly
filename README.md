# trimly
Trimly is a modern booking and business management platform designed for barbershops and salons. It enables customers to discover services, schedule appointments in real time, and complete secure M-PESA payments, while helping business owners efficiently manage bookings and customer interactions from a single platform.

✨ Features
#Customer Features
-Real-time appointment booking
-Service selection and scheduling
-Secure M-PESA payments
-Booking confirmation and status tracking
-Mobile-friendly user experience

#Business Features
-Appointment management dashboard
-Customer management
-Service and pricing management
-Schedule availability control
-Booking analytics and insights

#Payment Integration
-Safaricom M-PESA (Daraja API)
-Secure payment processing
-Automated payment verification
-Transaction tracking

🚀 Getting Started
Clone the repository
Install dependencies

Frontend:
cd frontend
npm install

Backend:
cd backend
npm install

Configure Environment Variables

Backend .env
DATABASE_URL=postgresql://postgres:password@localhost:5432/trimly

MPESA_CONSUMER_KEY=
MPESA_CONSUMER_SECRET=
MPESA_SHORTCODE=
MPESA_PASSKEY=
MPESA_CALLBACK_URL=
MPESA_CALLBACK_TOKEN=

Run the application
Backend:
npm run start:dev
Frontend:
npm run dev

🏗 Open the application
Frontend: http://localhost:3000
API Docs: http://localhost:5000/api/docs

🎯 Project Goals

Trimly was built to digitize appointment scheduling for barbershops and salons by providing:

-A seamless customer booking experience,
-Efficient business management tools,
-Secure mobile payment integration,
-Scalable cloud-ready architecture.

💡 Key Challenges Solved
-Real-time appointment scheduling,
-Prevention of double bookings,
-M-PESA payment integration,
-Secure transaction verification,
-Responsive user experience across devices.
